# Policies

* [AI covenant](ai-covenant.md) - The rules for AI-assisted work here: a person owns every contribution, an element says what DPV says, a rule states only what DPV states, and a mapping is DPV's own or it is absent.
* [Licence and attribution](license-and-attribution.md) - Whose work each part is: the code and the schema under Apache-2.0, the bundle under CC BY 4.0, and DPV's files and the text taken from them under the W3C Software and Document License, which NOTICE reproduces.
* [Security policy](security-policy.md) - How to report a vulnerability, what this repository releases, what executes here and what holds each surface. A report goes through GitHub's private vulnerability reporting, and only the latest release receives fixes.
