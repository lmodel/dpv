# Security policy

Use GitHub's private vulnerability reporting. Only the latest release receives fixes.[^security]

The repository's text and DPV's are data: tests validate the catalogue, and nothing executes or renders it.[^security]

A problem in DPV itself belongs with the Community Group.[^security]
